Projects

Delivered capability, work in progress, and planned development.

Guardian is an EHS management platform assembled from discrete modules rather than a single monolithic application. Each exists because an operational task required it. This page records the current status of every module, including those still under research.

Live

Permit to work

The module the platform is built around: work-type checklists, gas testing, task risk assessment and isolation references, a Draft-to-Issued workflow, a rule-based offline determination and a signature-ready document.

Shipped · used daily
Live

Audit & findings register

Set the audit basis, log findings as NC, observation or OFI with owners and dates, attach evidence, print the report.

Shipped
Live

Daily register & KPIs

Fourteen activity metrics per day, day-against-cumulative KPIs, a fourteen-day trend, an issued daily report and CSV export for analysis.

Shipped
Live

Offline reference engine

Fifty EHS topics with deterministic calculators — 5×5 risk scoring, LTIFR and TRIR, gas acceptance limits, and threshold rules for excavation depth, working height, noise and manual handling. No model required.

Shipped
Building

Realtime organisation sync

Permit decisions and register entries are delivered to every signed-in member as they occur, directly from the database.

Guardian models

A fine-tuned compact model for EHS responses capable of running on site hardware, together with a retrieval layer over an organisation's own procedures, standards and incident history, so answers cite internal documents rather than general practice.

Planned

Self-hosted deployment

A packaged installation for a private server or a single-board computer on the site network, for organisations that will not place safety data in third-party cloud infrastructure.

Planned

Project management assistant

The second model on the platform: programme risk, schedule pressure, resource loading and readiness, assessed against the same site record the safety function already maintains — so a delay and its safety consequence are considered together.

Next model after EHS
Planned

Cyber-security assistant

For organisations whose site systems, surveillance and OT networks require the same discipline as physical safety: access control, patching, incident response and the reporting that follows. The same permissions model and offline-first behaviour apply.
